# Unio

**Unio is union management software**: dues, dispatch, training and a member portal, so a union local can run its day-to-day in one place and its members can see what matters to them.

We're built in Newfoundland by [Sevenview Studios](https://sevenview.ca), working closely with the unions we serve.

**Open source from the team:** tools we built along the way and share openly:

- **saltbox-ui**: our UI components
- **saltbox-pg-backup**: PostgreSQL backups
- **sort_by_columns**: sortable columns for Rails
